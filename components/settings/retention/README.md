# Retention policy

Explicit content and history durations with room for backup and unfinished-upload settings.

Inputs: `id`, `title`, `description`, `content_days`, `history_days`, translated labels, `unit`.
Optional submitted `content_name`, `history_name` and string bounds `content_max="365"`, `history_max=""`.
Slot: related fields or effects notice. Host owns limits and deletion semantics.
Dependencies: forms/number and foundation. JavaScript: none.
