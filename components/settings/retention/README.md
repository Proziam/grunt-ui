# Retention policy

Explicit content and history durations with room for backup and unfinished-upload settings.

Inputs: unique `id`, `title`, `description`, `content_days`, `history_days`, translated labels, `unit`.
Optional submitted `content_name`, `history_name` and string bounds `content_max="365"`, `history_max=""`.
Slot: related fields or effects notice. Blue settings panel; fields stack with the available width.
Host owns limits and deletion semantics. The labelled fieldset retains native number validation.
Dependencies: forms/number and foundation. JavaScript: none.
