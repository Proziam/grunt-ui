# Unsaved Changes

Choose between saving and discarding pending edits.

Inputs: unique `id`, `title`, `description`, `preview=false`. Slots: none.
Behavior: `gui:modal-action` with `discard`; `gui:modal-submit` with `save`. Host owns persistence and dismissal.
Dependencies: `modals/modal-template`, local save icon. Figma source: 03.
