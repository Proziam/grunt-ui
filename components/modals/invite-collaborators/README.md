# Invite Collaborators

Invite several colleagues by email after creating a project.

Inputs: unique `id`, initial `emails`, `title`, `description`, `preview=false`. Slots: none.
Behavior: add/remove native email fields; `invite` submission contains repeated `emails`. Host sends invitations.
Dependencies: `modals/modal-template`, `forms/repeating-list`, local users icon. Figma source: 12.
