# Assign Post

Choose a team member to work on a published post.

Inputs: unique `id`, `(value, label)` `members`, selected `value`, `title`, `description`, `preview=false`, `expanded=false`. Slots: none.
Behavior: `assign` submission contains `member`; member selection is local until submitted.
Dependencies: `modals/modal-template`, `modals/post-published`, `forms/person-select`. Figma source: 08.
