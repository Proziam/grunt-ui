# Assign Post — Expanded

The team-member assignment dialog with its picker open above the field.

Inputs: unique `id`, `(value, label)` `members`, `value`, `title`, `description`, `preview=false`. Slots: none.
Behavior: live selection, Escape and outside-click dismissal; `assign` submission. The initial overlay intentionally covers the header.
Dependencies: `modals/assign-post`. Figma source: 09.
