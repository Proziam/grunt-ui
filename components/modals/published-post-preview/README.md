# Published Post Preview

Show a published post's cover image with copy-link and finish actions.

Inputs: unique `id`, `image`, `image_alt`, sharing `url`, `title`, `description`, `preview=false`. Slots: none.
Behavior: actual clipboard copy with live feedback; `finish` submission. Published state is caller supplied.
Dependencies: `modals/modal-template`, `actions/button`, `actions/copy-value`, local copy icon. Figma source: 18.
