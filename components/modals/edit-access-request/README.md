# Edit Access Request

Review a teammate's request to edit a project.

Inputs: unique `id`, requester `name`, `email`, `initials`, `image`, `project`, `project_url`, `title`, `preview=false`. Slots: none.
Behavior: `grant-access` submission; host authorizes access. Project uses a native link.
Dependencies: `modals/modal-template`, `display/feature-icon`, `people/identity`, local invite icon. Figma source: 11.
