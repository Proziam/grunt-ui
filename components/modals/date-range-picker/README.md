# Date Range Picker

Choose a date range using a calendar, shortcuts or native date fields.

Inputs: unique `id`, ISO `start` and `end`, `month` as YYYY-MM, optional ISO `today`, `preview=false`. Slots: none.
Behavior: native date validation; `apply-range` submission includes `start` and `end`. Changes remain local until applied.
Dependencies: `modals/modal-template`, `forms/calendar`. Figma source: 20.
