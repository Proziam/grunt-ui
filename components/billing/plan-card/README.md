# Pricing plan card

A plan, feature list and explicit price period with an optional recommended treatment.

Inputs: `name`, `description`, formatted `price`, `period`, list `features`,
`badge_label`, `featured`. Action slot. Supply current provider-backed pricing.
Featured uses a violet outlined badge; both variants keep a neutral border and modest price scale.
The action slot fills the card width. Dependencies: display/badge, display/icon, foundation,
`images/billing/feature-check.svg` and the supplied action component. JavaScript: none.
