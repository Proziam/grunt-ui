# Person Select

A member picker with a native disclosure and keyboard-operable radio choices.

Inputs: unique `id`, `name`, `label`, `(value, label)` `options`, optional `value`, `placeholder`, `expanded=false`.
Slots: none. Behavior: selection updates the summary and emits native change; Escape closes, Arrow Down enters options. Menu opens upward; allow space above.
Dependencies: `display/icon`, foundation, local user and chevron assets; optional behavior module.
