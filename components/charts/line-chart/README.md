# Line chart and sparkline

A scalable SVG trend with an accessible exact-value table.

Inputs: unique `id`, `title`, `description`, server-calculated `points` in a 600×180
view box, `(label,value)` `rows`, `value_label`. Supply points and rows from the same
series. This component draws prepared data; it does not fetch or infer scales.
Dependencies: foundation. JavaScript: none.
