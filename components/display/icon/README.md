# Icon

Small authored inline SVG marks with consistent stroke and accessible labelling.

Inputs: `name=check/close/plus/search/arrow/arrow-left/binding/clock/warning/inbox/settings/mail/workflow/lock/file/info`,
optional `label`, numeric `size=20`. Omit label for decorative icons next to text.
Optional `image` renders a supplied SVG/image at its intrinsic dimensions instead of the inline mark.
Dependencies: none (or the supplied asset). JavaScript: none.
