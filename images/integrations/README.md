# Integration service icons

SVG exports of the service artwork in Page 1 → Grunt / Integrations in
[Figma](https://www.figma.com/design/J704mKQTVAYpFBsghMLupi/Untitled?node-id=1-42).

Use as images with empty alternative text when the service name is adjacent.
The build discovers SVGs under `images/`; `grunt_ui::asset` serves their exact
relative paths, and the catalog export copies them into the same folder.
